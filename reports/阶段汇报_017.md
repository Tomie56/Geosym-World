# 阶段汇报 017：Isosceles Triangle Theorem-Lite

## 本阶段目标

本阶段继续补 theorem-lite。此前已有：

- right triangle / Pythagorean check；
- circle chord / central angle；
- angle bisector numeric residual；

但三角形基础定理里还缺少等腰三角形。等腰三角形是几何推理中很常见的诊断点，适合作为轻量 theorem-lite：

```text
AB = AC
  -> base angle ABC = base angle ACB
```

## 新增 facts

`FactClosureSolver` 现在会对 2D 三角形 polygon 检查等边关系。如果某个顶点到另外两个顶点距离相等，则生成：

```text
isosceles_triangle(triangle|apex:A)
equal_base_angles(triangle|apex:A)
equal_base_angle_residual(triangle|apex:A)
```

其中：

```text
equal_base_angle_residual = left_base_angle - right_base_angle
```

如果等腰定理成立，residual 应为 `0`。

metadata 中会保存：

- `polygon`
- `apex`
- `base`
- `equal_sides`
- `side_length`
- `left_base_angle`
- `right_base_angle`

这能支持后续 GeoSym-Debug 判断模型是否正确利用“等边推出等角”。

## 新增 Pilot 样本

新增：

```text
pilot_isosceles_base_angles
```

核心结构：

```text
A = (0, 2)
B = (-1, 0)
C = (1, 0)

AB = AC = sqrt(5)
target = equal_base_angle_residual(tri_ABC|apex:A)
```

目标答案：

```text
0
```

## 当前意义

这一步把等腰三角形从纯坐标事实扩展成 theorem-lite 诊断关系：

```text
side length equality
  -> isosceles_triangle
  -> equal_base_angles
  -> numeric residual
  -> target lookup
```

后续如果模型在等腰三角形问题中没有使用等边等角，或者角度计算出错，可以直接用 `equal_base_angle_residual` 做诊断。
