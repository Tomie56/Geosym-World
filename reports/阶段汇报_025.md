# 阶段汇报 025：Section Perimeter、退化检查与统一 Space Angle

## 本阶段目标

上一阶段已经让自动截面进入可计算面积。本阶段补三个收口能力：

- `section_perimeter`：截面周长 target；
- `section_degeneracy_measure`：截面退化度量；
- `space_angle`：统一 3D line-line、line-plane、plane-plane angle 的审计 schema。

## 代码改动

### 1. Section perimeter

`FactClosureSolver._section_relation_facts` 在存在 materialized section polygon 时新增：

- `section_perimeter`

它复用现有 `_closed_polyline_length`，直接基于 3D polygon vertices 计算闭合折线长度。

### 2. Section degeneracy measure

新增：

- `section_degeneracy_measure`

当前使用 section polygon area 作为非退化度量：

```text
section_degeneracy_measure = section_area
```

metadata 中标记：

```json
{"expected_nonzero": true}
```

它不是布尔判定，而是为了后续自动过滤退化截面提供可审计数值。

### 3. Unified space angle

新增 `space_angle` 聚合 fact，不替代原有 facts：

- 3D line-line：`rule=space_line_line_angle`
- 3D line-plane：`rule=space_line_plane_angle`
- plane-plane：`rule=space_plane_plane_angle`

metadata 用 `kind` 区分：

- `line_line`
- `line_plane`
- `plane_plane`

这样 manifest 可以直接统计 `space_angle_3d`，同时保留原有 `angle`、`line_plane_angle`、`dihedral_angle`。

### 4. Pilot samples

新增两个小型 pilot：

- `pilot_3d_auto_section_perimeter`
  - target: `section_perimeter(section_mid_perim)`
  - expected value: `1 + sqrt(2)/2`
- `pilot_3d_space_angle`
  - target: `space_angle(diag_OD|base_plane)`
  - expected value: `pi/4`
