# 阶段汇报 007：真实旧 GeoSym 样本 Adapter 抽样对接

## 本阶段目标

本阶段从仓库已有输出中抽样读取旧 GeoSym 真实 JSON/JSONL，而不是继续使用手写 fixture。目标是验证 `LegacyGeometryAdapter` 是否能承接旧 2D synthetic 输出和已有 3D prototype 输出。

## 观察到的旧 2D 字段

抽样文件：

```text
datas/synthetic_runs/verify_run/json/final/shaded_with_gt_20260629_183644_296.jsonl
```

关键字段：

- `points`: list，每个点有 `id`, `x.expr`, `y.expr`；
- `lines`: list，每条线段有 `id`, `start_point_id`, `end_point_id`；
- `entities`: list，形状对象中有 `id`, `type`, `vertices`, `lines`, `area` 等；
- `shadow_regions`: 可能存在，但本次样本为空；
- final JSON 没有统一 target 字段，因此 CLI 支持用 `--target-type` 和 `--target-object` 手动指定。

本阶段已扩展 adapter 支持：

- `x.expr / y.expr / z.expr` 坐标；
- `start_point_id / end_point_id`；
- `entities[*].vertices` 到 polygon；
- `edges` 到 segment；
- `faces` 到 3D polygon；
- `entities[*].faces` 到 polyhedron。

## 观察到的 3D prototype 字段

抽样文件：

```text
output/solid_geo_test/json/solid_0000_solved.json
```

关键字段：

- `points`: 3D 点，含 `x.expr`, `y.expr`, `z.expr`；
- `edges`: 含 `start_point_id`, `end_point_id`；
- `faces`: 含 `vertices`；
- `entities`: composite solid，含 `vertices`, `edges`, `faces`。

adapter 现在可以把这些字段转换为：

- `add_point3d`
- `add_segment`
- `add_polygon`
- `add_polyhedron`

## 抽样验证结果

### 旧 2D final JSONL

命令：

```bash
python -m geosym_world_geometry.tools.adapt_legacy_json \
  --input datas/synthetic_runs/verify_run/json/final/shaded_with_gt_20260629_183644_296.jsonl \
  --input-jsonl \
  --line-index 0 \
  --output geosym_world_geometry/outputs/adapted_legacy2d_final_line0.json \
  --record-id adapted_legacy2d_final_line0 \
  --question 'Find the length of L0.' \
  --answer 3 \
  --target-type length \
  --target-object L0
```

结果：

- `num_trace_ops = 18`
- `num_facts = 84`
- `verification_valid = true`
- target value: `3`

### 旧 3D prototype JSON

命令：

```bash
python -m geosym_world_geometry.tools.adapt_legacy_json \
  --input output/solid_geo_test/json/solid_0000_solved.json \
  --output geosym_world_geometry/outputs/adapted_legacy3d_solid_0000.json \
  --record-id adapted_legacy3d_solid_0000 \
  --question 'Find the volume of the adapted solid.' \
  --target-type volume \
  --target-object composite_1
```

结果：

- `num_trace_ops = 89`
- `num_facts = 602`
- `verification_valid = true`
- target value: `204*sqrt(2)`

## 当前边界

- 旧 2D JSON 的 `shadow_regions` 尚未转成组合区域；
- 旧 2D 的 `entities` 只先转 polygon，没有保留 parallelogram/trapezoid 等高阶类型语义；
- 3D prototype 的 volume 当前由新 world 的 polyhedron face formula 计算，尚未和旧 solver 的 metadata 做逐项比对；
- adapter 仍然是抽样对接，不是批量稳定转换器。

## 下一步

1. 增加 `adapter_report`，记录哪些字段被使用、哪些字段被跳过。
2. 对 2D `shadow_regions` 做区域转换。
3. 对 3D 输出比对旧 solver 中的 volume/surface area 字段。
4. 给 `adapt_legacy_json.py` 增加 `--summary-only` 或 `--write-trace`，方便定位真实样本字段映射问题。
