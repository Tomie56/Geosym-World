# 阶段汇报 026：Schema 文档与 In-Memory Smoke Check

## 本阶段目标

前面已经连续补充了 2D theorem-lite 与 3D formal interface。本阶段开始做质量收敛，重点不是继续扩展能力，而是让当前系统更容易审计和维护：

- 增加英文 schema 文档；
- 增加不写文件的最小 smoke check；
- 保持 pilot export 作为集成验证路径。

## 新增文档

geosym_world_geometry/docs/FORMAL_SCHEMA.md

## 新增 smoke check

新增：

```text
geosym_world_geometry/tools/smoke_check.py
```

特点：

- 直接调用 `PilotBenchmarkExporter().build_records()`；
- 全程 in-memory，不写新的数据文件；
- 检查所有 pilot record 都 valid；
- 抽查关键 target；
- 检查 theorem family 覆盖是否包含核心 family。

当前抽查 target：

| record | expected target |
|---|---|
| `pilot_3d_auto_section_area` | `section_area(section_mid_area)=1/8` |
| `pilot_3d_auto_section_perimeter` | `section_perimeter(section_mid_perim)=sqrt(2)/2 + 1` |
| `pilot_3d_space_angle` | `space_angle(diag_OD\|base_plane)=pi/4` |
| `pilot_parallel_cut_similarity` | `parallel_cut_ratio_residual(...)=0` |
| `pilot_tangent_chord_angle` | `tangent_chord_angle_residual(...)=0` |

Required theorem families:

- `angle_bisector`
- `circle_chord`
- `circle_tangent_angle`
- `dihedral_angle_3d`
- `inscribed_angle`
- `isosceles_triangle`
- `line_plane_3d`
- `projection_3d`
- `right_triangle`
- `similar_triangle`
- `solid_section_3d`
- `space_angle_3d`
