# 阶段汇报 001：Formal Geometry World 原型

## 当前目标

本阶段开始把 GeoSym 从“几何数据生成器”升级为“可执行几何世界”。新代码全部放在 `geosym_world_geometry/`，不改动旧的 `geosym/`、`scripts/` 和 `geosym3d/` 主流程。

## 已完成内容

- 建立独立包 `geosym_world_geometry`。
- 定义可重放的 `ConstructionOp`。
- 定义 `FormalGeometryState`，统一注册点、线、线段、射线、圆、多边形、区域、平面、多面体和目标。
- 实现 2D 构造执行器，已覆盖：
  - `add_point`
  - `add_segment`
  - `add_line`
  - `add_ray`
  - `add_circle`
  - `add_polygon`
  - `add_region`
  - `midpoint`
  - `intersection_line_line`
  - `parallel_through`
  - `perpendicular_through`
  - `line_through_angle`
  - `rotate_ray`
  - `angle_bisector`
  - `foot_of_perpendicular`
  - `point_on_ray_distance`
  - `point_on_segment_ratio`
  - `set_target`
- 预留立体几何接口，当前支持：
  - `add_point3d`
  - 3D `add_segment`
  - `add_plane`
  - `add_polyhedron`
- 实现第一版坐标事实闭包 `FactClosureSolver`，可推出：
  - 对象存在事实；
  - 线段长度；
  - 多边形面积；
  - 共享顶点角；
  - 平行、垂直；
  - 点在线上、点在线段上；
  - 三点共线；
  - 中点、角平分线等构造事实；
  - target fact lookup。

## 抽样验证

新增样例：

```bash
python -m geosym_world_geometry.examples.sample_trace
```

样例覆盖普通有角度相交构造：

```text
A = (0, 0)
B = (4, 0)
l_AC: through A with angle pi/6
l_BC: through B with angle 2*pi/3
C = intersection(l_AC, l_BC)
```

并额外覆盖中点、角平分线、垂足和 3D 平面/四面体接口。

## 下一步

1. 加入更系统的退化检查和 trace verifier。
2. 扩展圆相关构造：线圆交点、圆圆交点、切线、弦、圆心角/圆周角事实。
3. 扩展区域表达：阴影区域、扇形、组合区域和面积分解。
4. 为旧 `scripts/` 输出写 adapter，把旧 GeoSym 样本转换成 `FormalGeometryState + FactStore`。
5. 在小规模样本上导出 GeoSym-Hard / GeoSym-Debug pilot JSONL。
