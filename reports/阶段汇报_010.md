# 阶段汇报 010：Angled Line Intersection 与 Distance Fact Closure

## 本阶段目标

本阶段继续补 formal kernel 的基础事实闭包能力，重点处理两个缺口：

1. 任意角度相交直线已经可以通过 construction trace 构造，但 solver 还没有自动生成 line-line 交角事实。
2. 点对之间的距离只能通过显式 segment 的 `length` 得到，不能直接作为 `distance(A|B)` 查询。

这两个能力对于 GeoSym-Hard / GeoSym-Debug 很关键，因为后续很多诊断题不是只问某条已命名线段，而是需要判断点、线、辅助线之间隐含的几何关系。

## 新增能力

### 1. 无向直线夹角

在 `geometry.py` 中新增：

```python
undirected_angle_between(a, b)
```

它用于 line-like object 的夹角计算：

- 2D 中使用 `atan2(abs(cross), abs(dot))`；
- 3D 中使用 `acos(abs(dot)/(norm(a)*norm(b)))`；
- 方向相反的同一直线会得到 `0`，不是 `pi`。

### 2. 点对距离事实

`FactClosureSolver` 现在会在点数不超过 `max_combinatorial_points` 时，为同维度点对生成：

```text
type = distance
object = A|B
rule = point_distance_formula
```

这和显式 segment 的 `length` 并存：

- `length(AB)`：命名线段长度；
- `distance(A|B)`：两个点之间的坐标距离。

### 3. Line-like 交角与交点事实

对任意 line-like pair，包括：

- formal line；
- segment 诱导出的 line；

solver 现在会生成：

```text
angle(line1|line2)
```

如果是 2D 且不平行，还会生成：

```text
line_intersection(line1|line2)
metadata.coords = [...]
```

这使得“有角度的正常相交”不再只依赖 construction op 显式生成交点，而是能从状态本身自动闭包出交角和交点坐标。

## 新增 Pilot 样本

新增：

```text
pilot_angled_line_intersection
```

核心 trace：

```text
add_line(x_axis)
line_through_angle(tilt_60, base_line=x_axis, angle=pi/3)
intersection_line_line(X, x_axis, tilt_60)
midpoint(M, A, P)
perpendicular_through(perp_at_P, P, x_axis)
set_target(angle, x_axis|tilt_60)
```

这个样本同时覆盖：

- 任意角度直线构造；
- line-line intersection；
- midpoint；
- perpendicular_through；
- angle target lookup；
- point distance closure。

## 当前意义

这一步让 formal state 的事实闭包更接近几何推理需要的“流形状态”：

```text
construction trace
  -> exact objects
  -> point distances
  -> line-like angles
  -> line intersections
  -> target lookup
```

后续做 GeoSym-Debug 时，模型如果错在角度识别、辅助线交点、隐含距离关系上，benchmark record 里已经有可对照的 structured facts。
