# 阶段汇报 023：自动截面、线面角与 Face-Index 二面角

## 本阶段目标

上一阶段已经为 3D 投影、二面角和平面截多面体留出接口。本阶段继续补三个更实用的 3D 能力：

- 自动平面截多面体：从 polyhedron edges 与 plane 求交，自动生成 section boundary points；
- 线面角与线面距离：为任意 3D line-like object 与 plane 导出数值 facts；
- face-index 二面角增强：支持从 polyhedron face index 计算二面角，并记录 shared edge。

## 代码改动

### 1. 自动截面 helper

在 `geometry.py` 新增：

- `segment_plane_intersection_3d`

它对一条 3D segment 和一个 plane 做保守求交：

- 端点在 plane 上：返回端点；
- segment 穿过 plane：返回线性插值交点；
- 整条边在 plane 上：暂不展开为无限多个点；
- 不相交：返回 `None`。

### 2. 自动截面 construction

`section_polyhedron_with_plane` 现在支持两种模式：

- 显式 `boundary`：沿用上一阶段行为；
- 无 `boundary`：自动枚举 polyhedron edges，求交并生成点。

自动生成点命名为：

```text
{section_id}_p0, {section_id}_p1, ...
```

并写入 metadata：

- `constructed_by`: `section_polyhedron_with_plane`
- `polyhedron`
- `plane`
- `edge`

### 3. 线面角与线面距离 facts

在 `_plane_topology_facts` 中新增：

- `line_plane_angle`
- `line_plane_distance`

其中：

- `line_plane_angle = pi/2 - angle(line_direction, plane_normal)`
- 若 line 与 plane 相交，则 distance 为 `0`；
- 若 line parallel plane，则 distance 为 anchor 到 plane 的距离。

### 4. Face-index 二面角增强

`dihedral_angle` 现在可用：

```json
{"op": "dihedral_angle", "id": "...", "polyhedron": "...", "faces": [0, 1]}
```

solver 会：

- 根据 face index 取 face vertices；
- 用 face 前三个点计算 normal；
- 计算 `dihedral_angle`；
- 若两个 face 共享两个顶点，额外导出 `dihedral_shared_edge`。

### 5. Pilot samples

新增两个小型 3D pilot：

- `pilot_3d_line_plane_face_dihedral`
  - line-plane angle target: `diag_OD|base_plane = pi/4`
  - 同时包含 face-index 二面角 `dih_faces_0_1`
- `pilot_3d_auto_section`
  - plane `z=1/2` 自动截四面体；
  - target: `section_boundary_size(section_mid) = 3`
