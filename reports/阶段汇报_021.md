# 阶段汇报 021：平行截线相似与切线-弦定理

## 本阶段目标

继续减少 theorem-lite 中“纯坐标枚举”的比例，让 formal facts 更直接地连接 construction relation。本阶段新增两个能力族：

- `parallel_cut_similarity`：平行线截三角形得到相似三角形与比例 residual；
- `circle_tangent_angle`：切线-弦定理，对应 alternate segment angle。

## 代码改动

### 1. 平行截线相似

在 `FactClosureSolver` 中新增 `_parallel_cut_similarity_facts`：

- 遍历 2D 三角形对；
- 要求两个三角形共享一个 apex；
- 小三角形的两个 cut 点分别落在大三角形两条边上；
- cut 边与大三角形 base 平行；
- 导出：
  - `parallel_cut_similarity`
  - `parallel_cut_ratio_residual`
  - `similar_triangle` with `rule=parallel_cut_similarity`

当前 residual 使用两条边的比例平方交叉验证：

```text
AD^2 / AB^2 = AE^2 / AC^2
```

### 2. 切线-弦定理

新增 `_tangent_chord_angle_facts`：

- 读取 `tangent_points_from_point` 产生的 `tangent` relation；
- 读取同圆上的 `chord` relation；
- 当 tangent point 是 chord 的一个端点时，计算：
  - 切线与弦的夹角；
  - 圆上另一观察点对应的 alternate segment angle；
- 若二者相等，则导出：
  - `tangent_chord_angle`
  - `alternate_segment_angle`
  - `tangent_chord_angle_residual`

### 3. Pilot samples

新增两个小型 pilot：

- `pilot_parallel_cut_similarity`
  - 通过 `point_on_segment_ratio`、`parallel_through`、`intersection_line_line` 构造 `DE || BC`；
  - target: `parallel_cut_ratio_residual`
  - expected value: `0`
- `pilot_tangent_chord_angle`
  - 通过 `tangent_points_from_point` 构造切点；
  - 添加 chord `AB` 和观察点 `C`；
  - target: `tangent_chord_angle_residual`
  - expected value: `0`

### 4. Manifest family mapping

`pilot_exporter.py` 新增：

- `parallel_cut_similarity`
- `parallel_cut_ratio_residual`
- `tangent_chord_angle`
- `alternate_segment_angle`
- `tangent_chord_angle_residual`

## 下一步建议

下一阶段建议集中补 3D 接口的可解释 facts，而不是继续扩大量：

1. `solid_section_interface`：为平面截多面体预留接口与 relation；
2. `dihedral_angle`：二面角 fact schema 与最小 coordinate-backed 计算；
3. `projection_3d`：点到平面、线到平面的投影接口。

这样可以把当前 2D theorem-lite 的进展和用户最初要求的立体几何设计更好地合在一起。
