# 阶段汇报 031：垂线渲染、3D Hidden Line 与参数化批量生成

## 本阶段目标

本阶段修复三个具体问题：

1. 垂线没有真正画出来，只画了直角符号；
2. 立体几何没有处理遮挡关系，被遮挡的线没有虚线；
3. 合成样本太少，且生成参数不够可控。

## 垂线渲染修复

此前 `foot_of_perpendicular` relation 只派生了：

- 垂足点；
- right-angle marker。

现在额外生成：

```text
altitude:{source}-{foot}
```

作为 `auxiliary` segment primitive，使用虚线样式。

效果：

- `C -> H` 这种高线会明确画出来；
- right-angle marker 仍然保留；
- SVG 和 OpenCV PNG 都能显示。

新增测试：

```text
test_foot_of_perpendicular_renders_auxiliary_segment
```

## 3D Hidden Line

此前 polyhedron 所有边都是实线。现在在 renderer adapter 中增加了一个固定视角下的近似 hidden-line pass：

- 根据当前 3D 投影视角计算 camera vector；
- 对每个 face 估计 outward normal；
- 判断 front-facing / back-facing face；
- 若某条 edge 不属于任何 front-facing face，则标记为 hidden；
- hidden edge 使用 dashed style。

target polyhedron 也保留 hidden dashed，不再因为 target highlight 全部变成实线。

新增测试：

```text
test_polyhedron_hidden_edges_are_dashed
```

当前这是近似方法，不是严格 CAD hidden-line removal，但已经能表达常见四面体背面边虚线。

## 参数化批量生成

`synthesize_records.py` 增加参数：

```text
--families
--per-family
--mutations-per-variant
--grid-json
--grid-json-file
```

这使生成过程可以由命令行指定，不再只靠固定 smoke 规模。

示例：

```bash
python -m geosym_world_geometry.tools.synthesize_records \
  --output geosym_world_geometry/outputs/synthetic_v1/synthetic_v1.jsonl \
  --max-records 100 \
  --per-family 20 \
  --mutations-per-variant 2 \
  --format both \
  --seed 23
```

## 自动化 Template 构造

本阶段仍然没有手写大量独立 template。采用的是：

```text
TemplateFamily + parameter_grid + deterministic mutator
```

也就是说，模板数量来自参数空间展开，而不是人工写一堆 case。

现在可以通过 `--grid-json` 或 `--grid-json-file` 覆盖参数网格，例如：

```bash
python -m geosym_world_geometry.tools.synthesize_records \
  --families triangle_area_from_height \
  --grid-json '{"triangle_area_from_height": {"base": [3, 4, 5], "height": [2, 3], "skew": [1, 2]}}'
```

## 当前边界

3D hidden line 仍是 fixed-view approximate method，不是严格几何遮挡求解。

参数化生成已经可用，但 family builder 仍是内置的 5 类。下一步如果继续扩展，应做 grammar-level family composition，例如：

```text
base shape grammar + construction op grammar + target selection grammar
```

而不是继续增加独立 builder。
