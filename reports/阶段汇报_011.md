# 阶段汇报 011：3D Plane Interface 与保守事实闭包

## 本阶段目标

本阶段继续补立体几何接口。此前 formal world 已经支持：

- `add_point3d`
- `add_line` / `add_segment` 的 3D 点输入
- `add_plane`
- `add_polyhedron`
- 3D polygon area
- polyhedron surface area / volume

但 3D 平面相关 facts 还不够，导致立体几何样本只能验证体积和面积，不能表达基础的点-面、线-面、面-面关系。

本阶段目标是增加一组保守、坐标可验证、不涉及复杂 CAD 的 3D incidence facts。

## 新增几何 helper

在 `geometry.py` 中新增：

```python
point_on_plane(point, plane_point, plane_normal)
line_parallel_to_plane(line_direction, plane_normal)
```

这两个 helper 都只接受 3D 输入，底层基于点积判断：

- 点在平面：`dot(point - plane_point, plane_normal) == 0`
- 线平行平面：`dot(line_direction, plane_normal) == 0`

## 新增 3D facts

`FactClosureSolver` 现在会为 3D plane 生成以下 facts。

### 点-面关系

```text
point_on_plane(P|plane)
```

用于表示一个点满足平面方程。

### 线-面关系

```text
line_parallel_plane(line|plane)
line_on_plane(line|plane)
line_perpendicular_plane(line|plane)
line_plane_normal_dot(line|plane)
```

其中：

- `line_parallel_plane`：线方向和平面法向量垂直；
- `line_on_plane`：线平行平面且锚点在平面上；
- `line_perpendicular_plane`：线方向和平面法向量平行；
- `line_plane_normal_dot`：保留方向向量和法向量点积，便于后续做连续值检查。

### 面-面关系

```text
angle(plane1|plane2)
plane_parallel(plane1|plane2)
plane_perpendicular(plane1|plane2)
```

平面夹角使用法向量无向夹角，因此反向法向量不会导致错误的 `pi`。

## 新增 Pilot 样本

新增：

```text
pilot_3d_plane_relations
```

核心结构：

```text
O = (0, 0, 0)
X = (1, 0, 0)
Y = (0, 1, 0)
Z = (0, 0, 1)

base_plane = plane(O, X, Y)
wall_plane = plane(O, Y, Z)
vertical_OZ = line(O, Z)
axis_OX = line(O, X)
tetra_OXYZ = tetrahedron(O, X, Y, Z)

target = angle(base_plane|wall_plane)
```

该样本覆盖：

- 3D 点；
- 3D 线；
- 平面；
- 点在平面；
- 线在平面；
- 线垂直平面；
- 面垂直面；
- tetrahedron surface area / volume。

## 当前意义

这一步没有把 3D 做成完整 CAD 系统，而是把立体几何接口补到“可表达、可闭包、可验证”的最低可用状态：

```text
3D construction trace
  -> point / line / plane / polyhedron registry
  -> incidence facts
  -> plane relation facts
  -> surface / volume metrics
  -> target lookup
```

这样后续 GeoSym-Hard / GeoSym-Debug 可以先支持一类确定性的立体几何诊断样本，而不需要马上处理隐藏线、曲面、截面和渲染。
