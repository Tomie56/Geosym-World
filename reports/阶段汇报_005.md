# 阶段汇报 005：Theorem-Lite Facts 与 Manifest

## 本阶段目标

本阶段不做完整几何定理证明器，而是先加入一批稳定、坐标可验证的 theorem-lite facts，并为 pilot JSONL 导出补充 manifest，方便后续统计和筛样。

## Theorem-Lite Facts

新增位置：

- `solver.py`

当前新增事实类型：

- `right_triangle`
  - 从三角形三个顶点的坐标判断是否存在垂直边。
- `pythagorean_relation`
  - 对直角三角形验证 `c^2 - a^2 - b^2 = 0`。
- `central_angle`
  - 对圆中的 chord，计算该弦对应的圆心角。
- `chord_length_formula_check`
  - 验证弦长公式 `chord = 2r sin(theta / 2)`。
- `equal_chord_equal_central_angle`
  - 对同一圆中的等长弦，验证其对应圆心角相等。

这些 facts 都来自已有坐标和构造对象，因此是可验证的 theorem-lite，而不是依赖自然语言或 VLM 解析的 theorem claim。

## Manifest

新增导出 manifest：

```text
geosym_world_geometry/outputs/pilot_v0.jsonl.manifest.json
```

manifest 包含：

- 版本号；
- 样本数；
- 有效样本数；
- record ids；
- task type 统计；
- difficulty 统计；
- diagnostic axes 统计；
- fact type 统计。

## 抽样验证

新增样例：

```bash
python -m geosym_world_geometry.examples.sample_theorem_lite
```

该脚本会在内置 pilot 样本上统计 theorem-lite facts，并打印每类事实的样例。

## 当前边界

- 直角三角形 facts 只对显式 polygon triangle 生效。
- 圆相关 theorem-lite 目前依赖 `add_chord` 构造关系。
- 当前没有做相似、全等、圆周角、弦切角等复杂 theorem closure。
- `equal_chord_equal_central_angle` 需要同一圆中至少两条等长弦；当前内置 pilot 未必覆盖该事实，但 solver 已支持。

## 下一步

1. 增加专门覆盖等弦等圆心角的 pilot 样本。
2. 增加直角三角形派生目标样本，比如通过两直角边求斜边。
3. 为 manifest 增加 target value 分布和 fact dependency depth 统计。
4. 开始做旧 GeoSym 实际 JSON 的 adapter 对接。
