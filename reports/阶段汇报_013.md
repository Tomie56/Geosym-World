# 阶段汇报 013：Adapter Coverage Score

## 本阶段目标

此前 `LegacyGeometryAdapter` 的 report 已经包含：

- `input_keys`
- `op_type_counts`
- `used_ids`
- `preserved_metadata`
- `num_skipped`
- `skipped`
- `unhandled_top_level_keys`

这些字段能帮助人工判断适配情况，但后续如果要从旧 GeoSym 输出中抽样或筛选 formal records，还需要一个轻量的覆盖率指标。

本阶段新增 adapter coverage metrics。

## 新增字段

`adapter.report` 现在新增：

```text
coverage
coverage_score
```

其中 `coverage` 包含：

```text
coverage_score
key_coverage
item_success_rate
geometry_presence
total_top_level_keys
handled_top_level_keys
unhandled_top_level_keys
generated_ops
num_skipped
```

## Score 定义

当前 score 是一个保守的启发式指标：

```text
coverage_score = key_coverage * item_success_rate * geometry_presence
```

其中：

- `key_coverage`：顶层字段被 adapter 识别或保留的比例；
- `item_success_rate`：成功生成 construction op 的数量 / 成功生成与 skipped 总数；
- `geometry_presence`：是否至少生成了一个非 `set_target` 的几何 op。

这个 score 的用途是排序和过滤，不是数学正确性证明。数学正确性仍然依赖：

- trace verifier；
- construction execution；
- fact closure；
- target lookup；
- 后续 expected-fact 对齐。

## CLI 输出变化

`tools/adapt_legacy_json.py` 的 summary 现在会打印：

```text
coverage_score
coverage
```

这样抽样跑旧 JSONL 时，可以直接看到适配覆盖情况。

## 抽样验证

### 显式 shadow polygon fixture

输入：

```text
geosym_world_geometry/fixtures/legacy_shadow_region_polygon.json
```

结果：

- `verification_valid = true`
- `coverage_score = 1.0`
- `key_coverage = 1.0`
- `item_success_rate = 1.0`
- `generated_ops = 8`
- `num_skipped = 0`
- `target area(shadow_abc) = 6`

这个样本所有顶层字段都被识别或保留，且 shadow region 有显式边界，因此 coverage 满分。

### 旧 2D final JSONL shaded 样本

输入：

```text
datas/synthetic_runs/verify_run/json/final/shaded_with_gt_20260629_183644_296.jsonl
line-index = 1
```

结果：

- `verification_valid = true`
- `coverage_score = 0.9474`
- `key_coverage = 1.0`
- `item_success_rate = 0.9474`
- `generated_ops = 18`
- `num_skipped = 1`
- `target length(L0) = 3`

这个样本顶层字段都被识别或保留，但 `shadow_regions` 只有数量，没有边界几何，因此保留 metadata 的同时记录一次 skip，coverage 低于 1。

## 当前意义

这一步让 adapter 输出具备基础筛选能力：

```text
legacy record
  -> construction trace
  -> adapter report
  -> coverage metrics
  -> verification / fact closure
```

后续可以按 coverage score 快速筛掉低覆盖样本，再对高覆盖样本做更贵的 expected-fact 对齐或人工检查。
