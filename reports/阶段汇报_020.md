# 阶段汇报 020：AA 相似与 Arc-Backed 圆周角关系

## 本阶段目标

上一阶段已经补充了 SSS 相似三角形与坐标枚举式圆周角。本阶段继续往“构造关系驱动”的方向推进，重点做两件事：

- 为相似三角形增加 `AA similarity` 入口；
- 让圆周角不只依赖圆心角坐标计算，还能追溯到显式 `arc` construction relation。

## 代码改动

### 1. `add_arc` 现在保留 formal relation

`ConstructionBuilder._op_add_arc` 在注册 `Arc` 对象后，会额外写入一条 relation：

- `type`: `arc`
- `object`: arc id
- `circle`: 所属圆
- `start/end`: 弧端点
- `central_angle`: 显式圆心角
- `orientation`: 方向

这样 `arc` 不再只是一个对象，也成为后续 theorem-lite 可引用的构造关系。

### 2. 新增 AA 相似三角形 closure

在 `FactClosureSolver` 中新增 `_aa_similarity_facts`：

- 遍历 2D 三角形；
- 对三角形顶点排列建立 correspondence；
- 若至少两个对应角 residual 为 0，则导出：
  - `aa_similarity`
  - `aa_similarity_residual`
  - `similar_triangle` with `rule=aa_similarity`

这让相似三角形不再只能由 SSS 触发，也能由角关系触发。

### 3. 新增 arc-backed 圆周角 facts

在 `_inscribed_angle_facts` 中增加对显式 arc 的匹配：

- 若 arc 的端点与圆周角所对弦端点一致；
- 且 `inscribed_angle = arc_angle / 2` 或补弧关系成立；
- 则导出：
  - `arc_subtends_inscribed_angle`
  - `inscribed_angle_arc_residual`

这使得圆周角 fact 可以明确依赖 `arc:{arc_id}`，而不仅是依赖圆上点和圆心角。

### 4. Pilot samples

新增：

- `pilot_similar_triangles_aa`
  - target: `aa_similarity_residual`
  - expected value: `0`

更新：

- `pilot_inscribed_angle_same_chord`
  - 新增 `arc_AB`
  - target 从 `inscribed_angle_central_residual` 改为 `inscribed_angle_arc_residual`
  - target object: `APB|arc_AB`

### 5. Manifest family mapping

`pilot_exporter.py` 中新增 theorem family 映射：

- `aa_similarity`
- `aa_similarity_residual`
- `arc_subtends_inscribed_angle`
- `inscribed_angle_arc_residual`

## 下一步建议

后续可以继续补两类能力：

1. `parallel_cut_similarity`：平行线截三角形导致相似，适合连接 construction relation 与比例关系；
2. `circle_tangent_angle`：切线-弦定理，将 tangent construction 与圆周角关系连接起来。

这两类都能进一步减少“纯坐标枚举”的比例，让 formal system 更像一个可解释的几何推理世界。
