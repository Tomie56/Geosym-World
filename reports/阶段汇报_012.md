# 阶段汇报 012：Angle Bisector 数值级事实闭包

## 本阶段目标

此前 `angle_bisector` 已经可以作为 construction op 执行，并且 solver 会生成一个符号性的：

```text
equal_angle
```

但它还不能说明左右两个角的实际数值分别是多少，也不能提供一个可直接检查的 residual。这对 GeoSym-Debug 不够，因为诊断时需要知道模型到底错在：

- 没识别角平分线；
- 识别了角平分线但角度计算错；
- 或者 auxiliary line 本身构造错。

本阶段补上角平分线的数值级闭包。

## 新增 facts

当 construction relation 中存在：

```text
type = angle_bisector
line = bis_AOC
angle = [A, O, C]
```

solver 现在会额外生成：

```text
angle(AO|bis_AOC)
angle(bis_AOC|OC)
angle_bisector_residual(bis_AOC)
```

其中：

```text
angle_bisector_residual = left_angle - right_angle
```

如果该线确实是角平分线，则 residual 应为 `0`。

`angle_bisector_residual` 的 metadata 中会保存：

- `expected_zero`
- `left_angle`
- `right_angle`
- `mode`

这样后续可以把它直接作为 verifier / diagnosis 的数值证据。

## 新增 Pilot 样本

新增：

```text
pilot_angle_bisector_residual
```

核心结构：

```text
O = (0, 0)
A = (1, 0)
C = (0, 1)
bis_AOC = angle_bisector(AOC)
target = angle_bisector_residual(bis_AOC)
```

目标答案：

```text
0
```

## 抽样验证

重新导出：

```text
geosym_world_geometry/outputs/pilot_v0.jsonl
```

结果：

- `num_records = 7`
- `num_valid = 7`
- task types 新增 `angle_bisector`

对 `pilot_angle_bisector_residual` 的抽查结果：

- `target angle_bisector_residual(bis_AOC) = 0`
- `left_angle = pi/4`
- `right_angle = pi/4`
- `equal_angle(AO|bis_AOC, bis_AOC|OC)` 存在

## 当前意义

这一步让角平分线从“construction label”变成了“可验证的数值关系”：

```text
angle_bisector op
  -> equal_angle symbolic fact
  -> left/right angle facts
  -> residual numeric fact
  -> target lookup
```

后续 GeoSym-Debug 可以直接用 residual 判断模型是否正确利用了角平分线，而不是只看最终答案。
