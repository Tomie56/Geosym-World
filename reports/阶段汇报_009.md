# 阶段汇报 009：Legacy Shading Metadata 与 Shadow Region 适配

## 本阶段目标

本阶段继续增强 `LegacyGeometryAdapter`，重点处理旧 GeoSym 2D final JSON 中和图像、阴影区域相关的字段。

目标不是把图片解析成几何，而是把旧生成管线已经保存的 metadata 稳定保留下来，并在 legacy record 真的提供区域边界时映射成 formal region。

## 新增能力

`adapter.report` 现在新增：

```text
preserved_metadata
```

当前会保留：

- `raw_path`
- `annotated_raw_path`
- `shaded_path`
- `annotated_shaded_path`
- `shader_enabled`
- `shadow_type`
- `shadow_regions` 的数量与几何可用性判断
- `description`
- `base_id`
- `enhance_id`
- `is_base`
- `completed_rounds`
- `timeout_occurred`

CLI 输出 record 中也新增：

```text
adapter.preserved_metadata
adapter.report.preserved_metadata
```

这样后续构造 GeoSym-Debug 时，可以知道一个 formal record 是否有原图、标注图、阴影图，以及旧样本是否声称存在阴影区域。

## Shadow Region 映射策略

当前采用保守策略：

1. 如果 `shadow_regions` 是整数：
   - 只保留为 `shadow_region_count`；
   - 标记 `shadow_region_geometry_available = false`；
   - 不伪造 region；
   - 在 `report.skipped` 中记录 `shadow_region_count_without_geometry`。

2. 如果 `shadow_regions` 是 list，且 item 提供：
   - `polygon` / `polygon_id`，则映射为 `mark_polygon_region`；
   - `boundary` / `vertices` / `points`，则映射为 `mark_polygon_region`；
   - 同时 metadata 标记来源为 `legacy_shadow_regions`。

3. 如果 list item 没有可用边界，则跳过并记录原因。

这个策略避免把“有阴影数量”误解释成“有可验证几何区域”。

## 抽样验证

### 显式 shadow polygon fixture

输入：

```text
geosym_world_geometry/fixtures/legacy_shadow_region_polygon.json
```

输出：

```text
geosym_world_geometry/outputs/adapted_legacy_shadow_region_polygon.json
```

结果：

- `verification_valid = true`
- `num_trace_ops = 8`
- `num_facts = 28`
- `target area(shadow_abc) = 6`
- `shadow_region_geometry_available = true`

### 旧 2D final JSONL shaded 样本

输入：

```text
datas/synthetic_runs/verify_run/json/final/shaded_with_gt_20260629_183644_296.jsonl
line-index = 1
```

输出：

```text
geosym_world_geometry/outputs/adapted_legacy2d_final_line1_shaded.json
```

结果：

- `verification_valid = true`
- `num_trace_ops = 18`
- `num_facts = 84`
- `target length(L0) = 3`
- `shadow_region_count = 1`
- `shadow_region_geometry_available = false`
- `unhandled_top_level_keys = []`

这个结果说明旧 final JSONL 当前只提供了阴影区域数量和图片路径，没有提供阴影区域边界；因此 adapter 不能直接生成可验证 shaded-area region。

## 当前意义

这一阶段让旧 GeoSym final JSON 的图像侧信息进入 formal record：

```text
formal construction
  + exact facts
  + image/shading metadata
```

后续 GeoSym-Debug 可以基于这些 metadata 做：

- 图片与 formal state 对齐检查；
- shaded problem 的覆盖率统计；
- 过滤没有阴影几何边界的样本；
- 对有边界的 shadow region 直接生成 area target。
