## Template 的构造方法

没有手写大量 template，而是新增：

```text
geosym_world_geometry/synthesis/templates.py
```

核心是 `TemplateFamily`：

```text
family name + parameter grid + trace builder
```

当前内置 family：

| family | 构造方式 |
|---|---|
| `triangle_area_from_height` | base / height / skew 参数网格 |
| `angled_line_intersection` | base / left angle / right angle 参数网格 |
| `circle_sector` | radius / external tangent point 参数网格 |
| `parallel_cut_similarity` | triangle shape / cut ratio 参数网格 |
| `tetrahedron_section` | scale / section height / target type 参数网格 |

这是一种“少量 family 扩展出大量 trace variants”的方案，比手写大量独立模板更可维护。

## Sampler / Mutator

新增：

```text
geosym_world_geometry/synthesis/sampler.py
geosym_world_geometry/synthesis/mutators.py
```

`SyntheticSampler` 会遍历 template family variants，并可选地应用 deterministic mutator。

采样策略使用 family round-robin。这样即使只导出 10 条 smoke 数据，也不会全部来自第一个 family，而是覆盖三角形、角度交点、圆、相似、3D 截面等多类构造。

mutator 当前做保守变换：

- 坐标整体缩放；
- 2D/3D 平移；
- circle radius 同步缩放。

这样可以制造视觉和数值变化，同时尽量保持 formal relation 不被破坏。

## Difficulty Policy

新增：

```text
geosym_world_geometry/synthesis/difficulty.py
```

当前依据：

- op 数量；
- intersection op；
- angle bisector / tangent / section 等高级构造；
- 3D diagnostic axes；
- similar triangle axes。

输出 difficulty label 和 policy metadata。

## Degeneracy Rejection

新增：

```text
geosym_world_geometry/synthesis/filters.py
```

`DegeneracyRejector` 会检查：

- trace verification；
- construction execution；
- fact closure；
- target 是否存在；
- target fact 是否有值。

失败样例直接 reject，不进入导出。

## Duplicate Filtering

同在 `filters.py` 中实现 `DuplicateFilter`：

- 对 family / trace / question 做稳定 hash；
- 已见过的 hash 会被拒绝。

这是第一版语义 dedup，后续还应该增加 image hash 和 target-value dedup。

## Image + QA Record Exporter

新增：

```text
geosym_world_geometry/synthesis/exporter.py
geosym_world_geometry/tools/synthesize_records.py
```

CLI：

```bash
python -m geosym_world_geometry.tools.synthesize_records \
  --output geosym_world_geometry/outputs/synthetic_v0/synthetic_v0.jsonl \
  --max-records 10 \
  --format both
```

每条记录包含：

- `formal_state`
- `facts`
- `derivation`
- `verification`
- `synthetic` metadata
- `image.scene`
- `image.formats.svg`
- `image.formats.png`

## Intersection Schema

新增：

```text
geosym_world_geometry/intersections.py
```

核心结构：

```text
IntersectionResult
- kind
- status
- objects
- points
- parameters
- multiplicity
- metadata
```

当前支持：

- line-line；
- segment-segment；
- line-circle；
- circle-circle；
- `all/first/second/upper/lower/left/right` 选择。

旧 builder 暂时保持兼容；后续应该逐步把 construction op 路由到这个 schema。

## Renderer Style Randomization

新增：

```text
geosym_world_geometry/rendering/style_policy.py
```

`DeterministicStylePolicy` 支持基于 seed 的小幅风格扰动：

- stroke width jitter；
- color jitter；
- opacity jitter；
- label offset jitter。

同一 seed 输出确定一致，适合数据生成和回归。

## 当前边界

这仍然不是大规模生产引擎。当前是可审计 synthesis v0：

- template family 数量有限，但构造方法已经确定；
- rejection 是 target-level，不是完整几何质量判别；
- dedup 还不是 image-level；
- LLM trace proposal loop 还没接入；
- renderer style randomization 还比较轻量；
- builder 还未完全切到新 intersection schema。

下一步建议：

1. 把 builder intersection ops 接入 `IntersectionResult`；
2. 给 synthetic exporter 增加 image hash；
3. 增加 template-family grammar，而不是继续手动加 family；
4. 做 LLM-proposed trace 的 verifier/reject loop；
5. 把生成记录接到更完整的 benchmark manifest。
