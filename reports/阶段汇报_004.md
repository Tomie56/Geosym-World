# 阶段汇报 004：Pilot Benchmark Exporter

## 本阶段目标

本阶段把已有 formal geometry world 串成一个可导出的最小 benchmark 记录格式。目标不是生成大规模数据，而是先定清楚 GeoSym-Hard / GeoSym-Debug 的单条样本应该包含哪些内容。

## 新增模块

### 样本注册表

新增：

- `samples.py`

当前内置 3 个 pilot 样本：

1. `pilot_angle_triangle_area`
   - 覆盖有角度相交、中点、角平分线、垂足、三角形面积、3D 接口。
2. `pilot_circle_sector_area`
   - 覆盖线圆交点、切点、弦、弧、扇形面积、3D 多面体接口。
3. `pilot_legacy_adapter_length`
   - 覆盖 legacy-like dict 到 construction trace 的转换，以及 target length lookup。

### Pilot Exporter

新增：

- `pilot_exporter.py`

核心接口：

```python
from geosym_world_geometry import PilotBenchmarkExporter

summary = PilotBenchmarkExporter().write_jsonl("geosym_world_geometry/outputs/pilot_v0.jsonl")
```

每条记录包含：

```text
id
question
answer
formal_state
facts
derivation
verification
benchmark
```

其中：

- `formal_state` 保存可执行几何世界；
- `facts` 保存 fact closure；
- `derivation` 保存 target fact 的依赖子图；
- `verification` 保存 trace/state 检查结果；
- `benchmark` 保存 task type、difficulty、diagnostic axes、target value 和版本号。

### CLI

新增：

- `tools/export_pilot.py`

运行方式：

```bash
python -m geosym_world_geometry.tools.export_pilot \
  --output geosym_world_geometry/outputs/pilot_v0.jsonl
```

CLI 默认拒绝写到 `geosym_world_geometry/` 之外，避免生成数据散落到主仓其他目录。

## 当前记录格式价值

这个格式已经可以支撑后续 GeoSym-Debug 的基本诊断：

- 模型答案可和 `benchmark.target_value` 或 target fact 对齐；
- 模型推理中引用的对象可在 `formal_state` 中查验；
- 模型使用的几何事实可在 `facts` 中查验；
- target 依赖链可通过 `derivation` 回溯；
- 样本构造质量可通过 `verification` 过滤。
