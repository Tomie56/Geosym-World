# 阶段汇报 022：3D 投影、二面角与平面截多面体接口

## 本阶段目标

前面几轮主要推进 2D theorem-lite。本阶段回到最初要求中的立体几何设计，补三类 3D 接口与最小 coordinate-backed facts：

- `projection_3d`：点到平面、线到平面的投影；
- `dihedral_angle_3d`：二面角接口与数值 fact；
- `solid_section_3d`：平面截多面体接口，先保留 relation 与可验证 boundary。

## 代码改动

### 1. 3D geometry helpers

在 `geometry.py` 新增：

- `project_point_to_plane`
- `project_vector_to_plane`

二者都使用精确 SymPy 表达式，点投影公式为：

```text
P' = P - n * ((P - P0) dot n) / (n dot n)
```

### 2. 新增 construction ops

在 `ConstructionBuilder` 中新增：

- `project_point_to_plane`
  - 输入：`point`, `plane`
  - 输出：新的 3D point
  - relation: `point_projection_plane`
- `project_line_to_plane`
  - 输入：`line`, `plane`
  - 输出：新的 3D line
  - relation: `line_projection_plane`
- `dihedral_angle`
  - 当前支持 `planes: [plane1, plane2]`
  - 同时预留 `polyhedron + faces` 形式
  - relation: `dihedral_angle`
- `section_polyhedron_with_plane`
  - 输入：`polyhedron`, `plane`
  - 可选：`boundary`
  - relation: `polyhedron_plane_section`

### 3. 新增 fact closure

在 `FactClosureSolver` 中新增 relation-backed facts：

#### 点投影

- `point_projection_plane`
- `projection_distance`
- `projection_plane_residual`

#### 线投影

- `line_projection_plane`
- `line_projection_plane_residual`

#### 二面角

- `dihedral_angle`

当前用两个平面法向量的 undirected angle 作为二面角的最小可计算版本。

#### 截面接口

- `section_interface`
- `section_boundary_size`
- `section_boundary_plane_residual`

当前还不自动求平面与多面体的交线，只验证显式给出的 boundary 是否落在截面平面上。

### 4. Verifier 支持

`TraceVerifier` 新增对以下引用的静态检查：

- `plane`
- `polyhedron`
- `project_point_to_plane`
- `project_line_to_plane`
- `dihedral_angle`
- `section_polyhedron_with_plane`

### 5. Pilot samples

新增两个小型 3D pilot：

- `pilot_3d_projection_dihedral`
  - 点投影：`T -> H` 到 `base_plane`
  - 线投影：`top_line -> top_line_on_base`
  - 二面角：`base_plane` 与 `wall_plane`
  - target: `dihedral_angle(dih_base_wall) = pi/2`
- `pilot_3d_solid_section_interface`
  - 四面体 `tetra_OXYZ`
  - 截面 relation: `section_base`
  - boundary: `O, X, Y`
  - target: `section_boundary_plane_residual = 0`
