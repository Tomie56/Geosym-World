# 阶段汇报 018：Pilot Manifest 的定理族覆盖统计

## 本阶段目标

此前 `pilot_v0.jsonl.manifest.json` 已经能统计 `fact_type_counts`，但这个粒度偏底层：

- `angle`、`distance`、`point_on_line` 等基础事实数量很大，容易淹没真正的几何能力覆盖；
- 很难一眼判断当前 pilot 是否覆盖了直角三角形、等腰三角形、角平分线、圆弦、三维线面关系等研究主线；
- 后续如果要扩展成 GeoSym-Hard 或 debug benchmark，需要按“定理族/能力族”做覆盖审计。

因此本阶段在 pilot manifest 中增加 theorem family 级别的聚合统计。

## 新增内容

在 `pilot_exporter.py` 中加入了定理族归类逻辑，并在 manifest 中新增两个字段：

- `theorem_family_counts`：按定理族统计 formal facts 数量；
- `theorem_family_records`：记录每个定理族由哪些 pilot 样本覆盖。

当前归类覆盖：

- `right_triangle`
- `isosceles_triangle`
- `angle_bisector`
- `circle_chord`
- `line_plane_3d`

- `python -m compileall -q geosym_world_geometry`：通过；
- 已清理 `__pycache__`。

## 意义

这个改动让当前 formal system 的覆盖情况从“底层 fact 数量”提升到“几何能力族”层面。后续我们不需要逐条读 JSONL，就能快速判断：

- 哪些定理族已经有可验证样本；
- 哪些定理族只有少量样本，需要继续补；
- 新增样本是否真的扩展了几何能力，而不是只增加基础点线距离事实。

## 下一步建议

下一阶段建议继续补两个高价值能力族：

1. `similar_triangle`：相似三角形、比例关系、AA/SAS/SSS 判定、对应边比例；
2. `inscribed_angle`：圆周角、同弧所对圆周角相等、圆周角与圆心角关系。

这两个方向都适合 GeoSym-Hard：它们能把当前的基础 construction/fact closure 推向更接近竞赛几何与多步推理的状态。
