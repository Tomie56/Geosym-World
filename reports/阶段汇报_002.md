# 阶段汇报 002：圆、区域与立体接口扩展

## 本阶段目标

在第一版可执行几何世界基础上，补充圆相关构造、区域表达和更明确的立体几何接口。代码仍全部位于 `geosym_world_geometry/`，不影响旧 GeoSym 管线。

## 新增能力

### 圆与弧

新增对象：

- `Arc`

新增构造：

- `add_arc`
- `intersection_line_circle`
- `intersection_circle_circle`
- `tangent_points_from_point`
- `add_chord`

当前圆相关事实闭包支持：

- 半径；
- 圆周长；
- 圆面积；
- 点在圆上；
- 弧长；
- 扇形面积；
- 弦属于圆；
- 切点 / 切线关系。

### 区域表达

新增构造：

- `mark_polygon_region`
- `mark_sector_region`

当前区域事实闭包支持：

- 多边形区域面积；
- 3D 平面多边形区域面积；
- 扇形区域面积；
- 扇形对应弧长。

### 立体几何接口

第一阶段已经支持：

- `add_point3d`
- `add_plane`
- `add_polyhedron`

本阶段进一步在 fact closure 中加入：

- 3D 线段长度；
- 3D 多边形面积；
- 多面体表面积；
- 多面体体积。

这仍然是保守接口，不引入 CAD/OpenCascade，也不在当前阶段处理曲面体、截面、隐藏线渲染。

## 抽样验证

新增样例：

```bash
python -m geosym_world_geometry.examples.sample_circle_region
```

样例覆盖：

- 直径线与圆求交；
- 外点到圆的两个切点；
- 由两个切点形成弦；
- 半圆弧；
- 扇形区域；
- 3D 四面体接口；
- 扇形面积 target lookup。

## 当前边界

- 圆交点构造当前只支持 2D。
- 线圆、圆圆交点要求调用方给出正确数量的输出点 ID。
- 多面体体积基于有向三角面求和，要求 face orientation 合理；后续需要加入 orientation 修复或专门 solid builder。
- 暂未实现圆周角、弦切角、相似、全等等 theorem-level closure。
