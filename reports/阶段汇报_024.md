# 阶段汇报 024：自动截面 Polygon 与截面面积 Target

## 本阶段目标

上一阶段自动平面截多面体已经能生成 section boundary points。本阶段把它推进到可计算 benchmark：

- 自动截面点排序；
- 自动 materialize section polygon；
- 导出 `section_area` fact；
- 增加截面面积 pilot。

## 代码改动

### 1. 自动截面点排序

`section_polyhedron_with_plane` 在自动生成 boundary points 后，会基于截面平面建立一个局部二维坐标系：

- 取 plane normal；
- 构造平面内基向量；
- 以 boundary centroid 为中心；
- 按 `atan2` 对点排序。

排序只用于 polygon vertex order，坐标仍然保留精确 SymPy 表达式。

### 2. 自动生成 section polygon

当 section boundary 至少有 3 个点，且 `create_polygon` 未显式设为 `False` 时，builder 会自动注册：

```text
{section_id}_polygon
```

例如：

```text
section_mid_area_polygon
```

polygon metadata 会记录：

- `constructed_by`: `section_polyhedron_with_plane`
- `section`
- `polyhedron`
- `plane`

### 3. 新增 section facts

`FactClosureSolver._section_relation_facts` 新增：

- `section_polygon`
- `section_area`

其中 `section_area` 直接复用 3D polygon triangulation area。

### 4. Pilot sample

新增：

- `pilot_3d_auto_section_area`

几何设定：

- 四面体 `OXYZ`；
- 截面平面 `z=1/2`；
- 自动生成 3 个截面点；
- 自动生成 `section_mid_area_polygon`；
- target: `section_area(section_mid_area)`。

理论面积：

```text
1/8
```
