# 阶段汇报 019：补充相似三角形与圆周角 Theorem-Lite

## 本阶段目标

在不引入重型证明器、不生成大规模监督数据的前提下，继续扩展 `geosym_world_geometry` 的 formal geometry 能力。重点补两个更接近竞赛几何和 GeoSym-Hard 的能力族：

- `similar_triangle`：相似三角形、对应边比例、对应角 residual；
- `inscribed_angle`：圆周角、圆周角与圆心角关系、同弦同弧圆周角相等。

## 代码改动

### 1. 相似三角形 closure

在 `FactClosureSolver` 中新增 `_similar_triangle_facts`：

- 遍历 2D 三角形 polygon；
- 使用三边平方比例进行 SSS 相似判定，避免直接处理根号长度比例；
- 为匹配到的三角形对导出：
  - `similar_triangle`
  - `similarity_ratio_residual`
  - `similarity_scale_squared`
  - `equal_corresponding_angles`
  - `similar_angle_residual`

当前定位是 theorem-lite：用精确坐标验证事实，不声称做完整合成几何证明。

### 2. 圆周角 closure

新增 `_inscribed_angle_facts`：

- 在每个 2D circle 上枚举圆上点；
- 对弦端点 `A/B` 和观察点 `P` 推导 `inscribed_angle`；
- 同时检查：
  - `inscribed_angle = central_angle / 2`
  - 或补弧模式 `inscribed_angle + central_angle / 2 = pi`
- 为可验证情况导出：
  - `inscribed_angle`
  - `inscribed_angle_central_residual`
  - `equal_inscribed_angles`

### 3. Pilot samples

新增两个小型 pilot：

- `pilot_similar_triangles_sss`
  - 3-4-5 三角形与 6-8-10 三角形；
  - target: `similarity_ratio_residual`
  - expected value: `0`
- `pilot_inscribed_angle_same_chord`
  - 单位圆上四点；
  - target: `inscribed_angle_central_residual` for `APB|circle_O`
  - expected value: `0`

### 4. Manifest theorem family

`pilot_exporter.py` 的 theorem family 映射新增：

- `similar_triangle`
- `inscribed_angle`

## 质量说明

这一步没有扩大数据规模，只增加了两个可读、可调试的 pilot 样本。验证重点是：

- construction trace 可执行；
- target fact 能通过 fact closure 命中；
- theorem family manifest 能看到新增能力；
- `compileall` 通过；
- 已清理 `__pycache__`。

## 下一步建议

后续可以继续沿两条线推进：

1. 对 `similar_triangle` 增加 AA 相似入口，让角构造样本也能触发相似关系；
2. 对 `inscribed_angle` 增加更明确的 arc/sector 依赖，把“同弧/异弧”从坐标枚举提升为可解释的 formal relation。

这两步能让当前 theorem-lite 从“坐标事实验证”进一步靠近“构造关系驱动的几何推理”。
