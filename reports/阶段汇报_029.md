# 阶段汇报 029：Renderer 质量收敛

## 本阶段目标

上一版 renderer 已经能输出 SVG/PNG，但图像质量仍偏 debug 原型，主要问题包括：

- 无限直线直接延长，视觉上穿出画面太多；
- PNG 没有真正支持虚线；
- formal relation 没有转成几何符号，例如中点 tick、直角标记、角弧；
- label 固定偏移，容易压在线和点上；
- 3D 自动截面点 id 太长，直接画全名会污染图。

本阶段只做核心渲染质量改进，不做大规模数据生成。

## 代码改动

主要改动仍集中在：

```text
geosym_world_geometry/rendering/
```

### 1. Viewport clipping

`line` 和 `ray` 不再简单按很大 span 延长，而是在 world bounds 上做 clipping。

影响：

- 直线仍能表达“无限线”的语义；
- 画面不会被超长辅助线污染；
- SVG 和 PNG 使用一致的 clipping 逻辑。

### 2. PNG dashed line

OpenCV 的 `cv2.line` 没有原生 dasharray，本阶段实现了 `_draw_styled_line`：

- 对 `dasharray` 进行像素级分段；
- segment / line / ray 都支持；
- 与 SVG 的 `stroke-dasharray` 保持语义一致。

### 3. Geometry markers

新增 renderer-level marker primitive，不改变 formal state 和 solver：

| marker | 来源 relation | 作用 |
|---|---|---|
| `tick_marker` | `midpoint` | 标记两段等长 |
| `angle_marker` | `angle_bisector` | 标记被角平分的角 |
| `right_angle_marker` | `foot_of_perpendicular` / `perpendicular` | 标记直角 |

这些 marker 是从 construction relations 中派生，不污染 fact closure。

### 4. Label 可读性

改动：

- label offset 从固定值改成相对几何中心向外偏移；
- SVG text 增加白色 halo；
- PNG text 先画白色粗描边，再画深色文字；
- 长 id 自动缩写显示，例如 `section_mid_area_p0` 显示为 `p0`。

注意：显示名缩写不改变 formal id，SVG/scene 中仍保留 `label:{full_id}` 可追溯。

## 抽样验证

运行：

```bash
python -m geosym_world_geometry.tools.render_smoke_check
```

通过。抽样样例：

| sample | primitives | labels | markers |
|---|---:|---:|---:|
| `pilot_angle_triangle_area` | 16 | 5 | 4 |
| `pilot_3d_auto_section_area` | 15 | 8 | 0 |
| `pilot_3d_space_angle` | 6 | 4 | 0 |
| `pilot_circle_sector_area` | 11 | 6 | 0 |
| `pilot_tangent_chord_angle` | 8 | 6 | 0 |

smoke check 当前会检查：

- SVG 有合法 `<svg>`；
- SVG 保留 geometry `data-id`；
- PNG 可被 OpenCV 读取；
- PNG 尺寸正常；
- PNG 非空白；
- 至少一个 smoke 样例覆盖 marker primitive。

## 人工抽查

抽查 `pilot_angle_triangle_area.png`：

- 2D target-aware filtering 生效，没有附带的 3D tetrahedron；
- 辅助线为虚线；
- 中点 tick、直角标记、角弧可见；
- label 有 halo，和线条的冲突明显减少。

抽查 `pilot_3d_auto_section_area.png`：

- 3D tetrahedron 投影正常；
- 截面 polygon 高亮；
- 自动截面点显示为 `p0/p1/p2`，不再使用长 id 污染画面。

## 当前仍未解决

这版仍不是最终图像合成器：

- label 还没有全局避让优化；
- 3D 没有 hidden-line removal；
- angle marker 只从 construction relation 派生，还没有根据所有 angle facts 自动绘制；
- 没有 tick count、多组等长标记、平行线箭头标记；
- 没有 style randomization / deterministic seed policy。

## 下一步建议

下一阶段应该做两个方向：

1. **Render semantics**：补 parallel marker、multi-tick equal-length marker、right-angle marker from theorem facts。
2. **Data export**：让 pilot JSONL 可选携带 image path / render scene metadata，形成真正的 `trace -> state -> facts -> image -> record` 闭环。
