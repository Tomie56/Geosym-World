# 阶段汇报 028：Renderer v0 与 SVG/PNG 取舍

## 本阶段目标

本阶段开始把 formal geometry world 接到图像合成链路上。目标不是大规模生成监督数据，而是先完成一个可维护的最小闭环：

```text
FormalGeometryState -> RenderScene -> SVG / PNG
```

新增代码、工具、输出仍然全部放在：

```text
geosym_world_geometry/
```

## SVG 还是 PNG

结论：当前阶段主格式选 SVG，同时兼顾 PNG。

### 为什么 SVG 作为主格式

SVG 更适合现阶段的 formal geometry debug：

- 文本可读，容易 diff；
- 每个几何对象可以保留 `data-id`，方便从图像元素追溯到 formal object；
- 线段、圆、弧、多边形、label 等几何 primitive 和 formal state 的对应关系清楚；
- 适合人工审计样例，尤其是检查 target highlight、辅助线、截面 polygon 是否正确。

### 为什么还要兼顾 PNG

PNG 更贴近后续训练/评测管线：

- 大多数视觉模型输入最终是 raster image；
- OpenCV 可以直接做像素级 smoke check；
- 后续可以自然加入线宽扰动、颜色扰动、抗锯齿、压缩等视觉 domain randomization。

本阶段没有采用 SVG 转 PNG，而是从同一个 `RenderScene` 分别输出 SVG 和 OpenCV PNG。这样可以避免额外转换依赖，并保证 SVG/PNG 共享同一套 scene adapter。

## 新增模块

新增目录：

```text
geosym_world_geometry/rendering/
```

核心文件：

| 文件 | 作用 |
|---|---|
| `scene.py` | renderer-neutral `RenderScene` / `RenderPrimitive` / `RenderStyle` / `RenderLabel` schema |

| `adapter.py` | `FormalGeometryState -> RenderScene` |

| `png_renderer.py` | OpenCV PNG 输出 |

新增工具：

| 文件 | 作用 |
|---|---|
| `tools/render_pilot.py` | 将 built-in pilot samples 渲染为 SVG/PNG |
| `tools/render_smoke_check.py` | 抽样渲染 5 个样例并做有效性检查 |

## 当前渲染能力

2D 当前支持：

- point；
- segment；
- line；
- ray；
- circle；
- arc；
- polygon；
- polygon region；
- sector region；
- point labels；
- target object highlight。

3D 当前支持：

- 固定正交投影；
- 3D points；
- 3D lines/segments；
- planes 的三点示意面；
- polyhedron edges；
- section polygon highlight；
- point labels。

adapter 默认使用 `include_3d="auto"`：

- 如果 target 是 2D，就过滤掉样例里为了接口验证附带的 3D 对象，避免图像变脏；
- 如果 target 是 plane/line-plane/dihedral/section/space-angle 等 3D 任务，就渲染 3D projection。

这个设计是本阶段一次重要修正。第一次 smoke 时发现 `pilot_angle_triangle_area` 会把附带的 tetrahedron 画进 2D 三角形题里，影响图像质量；现在通过 target-aware dimension filtering 解决。

## 验证结果

运行：

```bash
python -m geosym_world_geometry.tools.render_smoke_check
```

通过，抽样 5 个样例：

| sample | primitive count | label count |
|---|---:|---:|
| `pilot_angle_triangle_area` | 12 | 5 |
| `pilot_3d_auto_section_area` | 15 | 8 |
| `pilot_3d_space_angle` | 6 | 4 |
| `pilot_circle_sector_area` | 11 | 6 |
| `pilot_tangent_chord_angle` | 8 | 6 |

smoke check 会检查：

- SVG 文件包含 `<svg>` 和 geometry `data-id`；
- PNG 可以被 OpenCV 读取；
- PNG 尺寸正常；
- PNG 非白像素数量超过阈值，避免空白图误判通过。

输出目录：

```text
geosym_world_geometry/outputs/render_smoke/
```

也可以运行：

```bash
python -m geosym_world_geometry.tools.render_pilot \
  --output-dir geosym_world_geometry/outputs/rendered_pilot \
  --format both \
  --max-samples 5
```

## 当前边界

当前 renderer 是 v0 debug renderer，不是最终论文级图像合成器：

- 3D 只做固定正交投影，没有 hidden-line removal；
- angle marker、right-angle marker、parallel marker 还没有专门 primitive；
- label placement 目前是固定 offset，还没有避让算法；
- line/ray 会延长到 viewport 外，适合 debug，但后续需要 clipping 和风格策略；
- PNG 视觉风格仍然朴素，暂未加入随机扰动。

## 下一步建议

下一阶段建议按数据引擎方向推进：

1. 增加 angle marker / right-angle marker / tick marker / parallel marker；
2. 把 `RenderScene` 写入 benchmark record 的 metadata，形成可追溯图文样本；
3. 增加 style policy，支持 deterministic seed；
4. 给 renderer 加 pytest 单测，而不是只依赖 smoke；
5. 再做小规模 `trace -> state -> facts -> render -> jsonl` 的 integrated sample export。
