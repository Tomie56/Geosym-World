# 阶段汇报 003：Trace Verifier 与 Legacy Adapter

## 本阶段目标

本阶段补齐两个基础工程环节：

1. 在执行构造前检查 construction trace，避免坏样本进入 benchmark 导出。
2. 提供一个轻量 legacy adapter，把旧 GeoSym 或 synthetic-like 字典转换成新 formal world 的 trace。

所有新增代码仍位于 `geosym_world_geometry/`。

## Trace Verifier

新增文件：

- `verifier.py`

核心接口：

```python
from geosym_world_geometry import TraceVerifier

report = TraceVerifier().verify_trace(trace)
```

当前检查内容：

- 重复 ID；
- 未知点、线、线段、圆、多边形、射线引用；
- `add_point3d` 维度错误；
- 缺少 target 时给出 warning；
- 可选执行 trace，捕获运行时几何错误；
- 执行后检查 state 中的退化线段、重复多边形顶点、零半径圆、退化多面体等。

输出结构：

```text
static_valid
executable
state_valid
valid
issues
metrics
```

## Legacy Adapter

新增文件：

- `legacy_adapter.py`

核心接口：

```python
from geosym_world_geometry import LegacyGeometryAdapter

trace = LegacyGeometryAdapter().to_trace(record)
```

当前支持把 plain dict 中的以下字段转换为 construction trace：

- `points` / `vertices`
- `lines`
- `segments` / `edges`
- `circles`
- `polygons`
- `regions`
- `target`

这个 adapter 目前是 schema-tolerant 的桥，不依赖旧 `scripts/` 内部类。后续需要基于真实旧 GeoSym JSON 样本继续补字段映射。

## 抽样验证

新增样例：

```bash
python -m geosym_world_geometry.examples.sample_adapter_verifier
```

样例流程：

```text
legacy-like dict
  -> LegacyGeometryAdapter.to_trace
  -> TraceVerifier.verify_trace
  -> ConstructionBuilder.execute
  -> FactClosureSolver.solve
  -> export_record(..., verification=report)
```
