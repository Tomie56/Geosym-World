# 阶段汇报 006：等弦样本与 Legacy JSON 转换入口

## 本阶段目标

本阶段补齐 theorem-lite pilot 覆盖，并开始为真实旧 GeoSym JSON 对接准备稳定入口。

## 等弦等圆心角 Pilot

新增内置样本：

- `pilot_equal_chords_central_angle`

该样本在同一圆中构造两条等长弦：

```text
AB = 8
CD = 8
```

实际构造使用坐标：

```text
A = (3, 4), B = (3, -4)
C = (4, 3), D = (-4, 3)
```

两条弦都在半径为 5 的圆上，solver 会推出：

- `central_angle`
- `chord_length_formula_check`
- `equal_chord_equal_central_angle`

这补齐了第五阶段已经实现但没有被内置 pilot 覆盖的 theorem-lite fact。

## Legacy Adapter 扩展

新增支持字段：

- `chords`
- `arcs`

现在 plain dict 可以把弦和弧转换为：

- `add_chord`
- `add_arc`

这仍然是 schema-tolerant 适配层，不直接依赖旧 `scripts/` 的内部类。

## 单文件转换 CLI

新增：

- `tools/adapt_legacy_json.py`

用法：

```bash
python -m geosym_world_geometry.tools.adapt_legacy_json \
  --input path/to/legacy.json \
  --output geosym_world_geometry/outputs/adapted_legacy_record.json
```

输出内容包含：

- `formal_state`
- `facts`
- `derivation`
- `verification`
- `adapter`

CLI 会拒绝写到 `geosym_world_geometry/` 之外，避免实验文件散落到主仓。
