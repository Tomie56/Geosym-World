# Parser 重绘残留问题与样本来源复核

## 结论

复核对象是 `Geosym-World/artifacts/parser/evaluations/seed_repair_20260924/final/` 的八个样本。逐一对照 contact.png、冻结原始模型输出、ParseGraph、State 和 scene；没有调用模型、修改产品代码或重跑批量解析。

上一轮修的是关系假通过、目标保存与覆盖审计，最显著的图形错误仍在提取语义、单位转换、圆弧物化和显示信息传递中。增加这些检查有价值，但不能替代可见重建质量的修复。只用 382 个单元测试通过作为交付依据不够。

## 逐类根因

### 圆弦图：量纲错误与条件缺失叠加

原始模型给出了视觉半径 140；题目给定数学半径 14、弦 CD=22。原始 quantities 却把圆半径写成 `length(circle_A)=14`，没有明确 radius 角色，relations 也没有 B/C/D 在圆周上的条件。

实现器只将线段数值长度送入优化，点的位置缩到数学长度尺度；`_circle_radius` 则直接返回 radius_px，生成的 State 圆半径仍为 140。因而半径巨大、线段挤在中心，渲染器忠实画出了一个已经错误的 State。不能仅调整画布或把某个样本的半径除以十。

依据：`parser/seed_realizer.py::_numeric_length_targets`、`_refine_numeric_witness`、`_circle_radius`；冻结输出 `geometry3k_sample_c868b4771aa7c1e1.json`。

### 四分之一圆：表示契约没有打通

原始 O6 是 `arc(center=O2,start=O1,end=O3,radius=180)`。适配器的 arc 分支没有保留 radius；物化又要求它引用一个已有 circle，而不是接受中心和端点定义，因此 State 中没有外弧。

模型在摘要中写了内圆与两直边和外弧相切，但结构化 relations 没有这些约束。半径 6 也被写成弧的普通 length，无法参与当前数学求解。原图未显示的 A/B/C/K_center 标签则被模型写进 label 并进入重绘。

依据：`parser/openrouter.py::_normalize_compact_object_geometry`、`parser/seed_realizer.py::_materialize_state`；冻结输出 `mathvision_mathvision_173.json`。

### PGDP 面积图：模型条件不相容，优化器仍尝试折中

模型声明 CE 的端点是 C/E，同时声明 F 在 CE 上、CF 垂直 CE、CF=4。若这些条件成立，C/F 都在 CE 上，非零 CF 不可能垂直 CE。另把底边 AE=21 绑定到 AB，把从右上顶点到对角线的高度绑定到 CF，并把边界识别成错误的五边形。

当前优化器缺少求解前的结构矛盾定位，仍将这些条件组合求最小残差。观察位置的残差系数为 1e-6，而主要约束使用 8，布局只是极弱的参考；当条件矛盾时，形状可大幅偏离原图。结果正确报告了 F 在 CE 上和 CF 数值条件违反，但依然输出一个破坏原轮廓的 partial 图。

应先给出冲突条件及来源；冲突条件不能生成“合法重建”结论，也不能由后端按样本 ID 偷改端点。

### 三中线、菱形：几何关系在，符号不在

两个 State 各有三条 equal_length 关系。原始模型也输出了 tick_marks/display_annotations，但三中线 scene 中没有刻线 primitive；菱形只有直角标记，没有四边同组刻线。

当前 renderer 的刻线分支主要处理 midpoint，而 equal_length 关系没有完整的刻线分组映射。graph 级 display_annotations 又未成为统一的 State/scene 显示契约。平行符号由语义关系自动生成，原图的等长刻线却丢失，造成符号增删不一致。

同类问题包括：文字给定 JP=9、RP=3.5 自动加到原本没有数字的图上；原图虚线、匿名点和填充信息没有得到一致传递。应分别保存数学条件与源图可见样式，不能让默认合成样式代替源图样式。

### 矩形图：不要把显示问题误诊为数学构造失败

直接读取最终 State 得到 AB≈16、BC≈12、CE≈15，AB/BC 和 AC/CE 的方向归一化点积分别约 3.54e-15 和 1.61e-15。因此本轮矩形和指定直角关系实际成立。

直角 primitive 已存在，但使用线对象的存储方向，未统一从角顶点朝有效线段内部选取方向，符号会出现在角外。矩形自动填充、平行箭头以及目标 ACF 区域绑定缺失是独立问题；不能归结为“VLM 没识别出垂直”。

## 应调整的后续验收

先修统一尺度和圆弧表示，再修条件冲突处理及样式传递。保留上一轮审计，但以原图/重绘、对象拓扑、实际约束残差和缺失内容作为共同验收依据。结构种子允许非唯一坐标，不能允许不同对象使用不同单位、关键边界消失或矛盾约束被视为合法。

后续新增跨数据集样本前应核实原始下载来源、文件指纹和 synthetic 标志。不要继续把这八张历史回归图当作开放数据集泛化评估。
