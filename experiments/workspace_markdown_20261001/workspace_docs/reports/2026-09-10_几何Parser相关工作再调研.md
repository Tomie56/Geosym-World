# 几何 Parser 相关工作再调研

日期：2026-09-10。

## 1. 调研目的

本轮调研回答两个问题：

1. 其他工作所说的 geometry parser 到底在解析什么、输出什么；
2. Geosym-World 应直接复用哪些公开路线，又应把哪些能力保留为自己的系统边界。

本文只依据公开论文、官方项目页和公开数据卡归纳。论文结果尚未在本地复现，以下判断不是精度承诺或新颖性结论。

## 2. 核心结论

学界没有统一的“几何 Parser”定义。现有工作至少混用了六种任务：

1. **视觉元素理解**：检测图元、文字和符号，并将文字与图元对齐；
2. **场景图解析**：输出图元节点以及 geo2geo、text2geo、sym2geo 等关系边；
3. **形式语言生成**：直接把图片转成供 solver 使用的 literals 或准自然语言谓词；
4. **图文联合解释**：联合题干和图片选择一组相互一致的条件；
5. **参数约束重建**：从 raster 恢复可求解、可编辑的 primitives 和 constraints；
6. **绘图代码恢复**：生成 TikZ 等可执行代码，重点保证视觉重现和可编辑性。

这些任务有重叠，但不能互相替代。尤其是：

- 生成正确 TikZ 不等于恢复了数学语义；
- 输出合法 predicates 不等于这些 predicates 都有可定位的图像证据；
- solver 能求出答案不等于 Parser 忠实读取了原图；
- 一个数值 realization 满足条件，不等于这些条件由原图声明；
- 训练时与 GT 比较得到的“可验证奖励”，不等于真实运行时的无 GT admission。

因此，Geosym-World 中的 Parser 应定义为：

```text
公开图片 / 公开题干
  -> 可定位 evidence
  -> 带置信语义和冲突的 ParseGraph hypotheses
  -> 图文 grounding
  -> verifier-gated admission
  -> 可执行但不冒充唯一真值的 geometry realization
  -> 忠实度、结构和下游效用诊断
```

## 3. 代表路线

| 路线 | 代表工作 | 对 Parser 的理解 | 对本项目的直接价值 |
| --- | --- | --- | --- |
| 视觉元素与对齐 | [G-ALIGNER，AAAI 2014](https://ojs.aaai.org/index.php/AAAI/article/view/9146) | 识别视觉元素、位置和属性，并与文本描述对齐 | grounding 不是后，而是 Parser 主任务 |
| 候选解释选择 | [GeoS，EMNLP 2015](https://aclanthology.org/D15-1171/) | 图文两侧先过生成带分的 literals，再选择兼容、覆盖充分且不冗余的子 | 很接近 hypothesis + conflict resolution；不应过早只留一个答案 |
| 检测到 solver literals | [Inter-GPS，ACL 2021](https://aclanthology.org/2021.acl-long.528/) | Hough、目标检测和 OCR 生成形式条件，与规则文本 Parser 合并 | 是可复现的经典 baseline；但输出是扁平确定性 literals |
| 异质场景图 | [PGDPNet，IJCAI 2022](https://arxiv.org/abs/2205.09363) | 图元、文字、符号及多类关系组成特殊 scene graph | primitive、symbol、relation 分层和 PGDP5K 指标值得直接对接 |
| Diagram clauses | [PGPSNet-v2 / PGPS9K，2024](https://arxiv.org/abs/2407.07327) | 将图中结构和语义转成 textual clauses，作为推理解码器的额外模态 | 说明结构化描述对下游推理有用；其 verifier 主要验证解题程序，不是 Parser admission |
| VLM 自动形式化 | [Geo-TinyLLaVA，ICML 2025 Workshop](https://icml.cc/virtual/2025/52421) | 完整点标注图像直接生成 Geometry3K literals | 适合作为 image-to-literals 小模型 baseline；其前提是完整点标注且输出契约较窄 |
| 图文消歧 | [Pi-GPS，ICCV 2025](https://openaccess.thecvf.com/content/ICCV2025/papers/Zhao_Pi-GPS_Enhancing_Geometry_Problem_Solving_by_Unleashing_the_Power_of_ICCV_2025_paper.pdf) | 文本和图分别产生 propositions，再用图像信息消解文本指代 | 支持把 cross-modal disambiguation 独立成一层 |
| 形式表示预训练 | [DFE-GPS，ICASSP 2025](https://arxiv.org/abs/2409.04214)、[GeoX，ICLR 2025](https://openreview.net/pdf?id=6RiBl5sCDF) | 形式语言是视觉与语言之间的高密度监督或中间表征 | 可验证 formal representation 对模型有训练价值，但这类 solver 工作不等于完整 Parser 系统 |
| 统一 2D/3D 形式化 | [Geoparsing，Findings ACL 2026](https://aclanthology.org/2026.findings-acl.1494/) | MLLM 将平面和立体几何图直接生成统一形式描述 | 当前最接近的公开 Parser baseline，必须重点对接和比较 |
| 参数约束重建 | [Vitruvion，ICLR 2022](https://openreview.net/pdf?id=Ow1C7s3UcY)、[DAVINCI，2024](https://arxiv.org/abs/2410.22857) | raster 或草图转参数化图元和约束图，再交给 constraint solver | 直接启发 reconstruction、自由度诊断、编辑与约束保持变换 |
| 绘图程序恢复 | [DaVinci，ICLR 2026](https://proceedings.iclr.cc/paper_files/paper/2026/hash/8ef4d68682f79c6c9ff0e065232cf141-Abstract-Conference.html) | raster scientific diagram 转 TikZ，联合优化视觉、结构和代码正确性 | 可作为 source redraw 和视觉 fidelity 对照，不可替代数学 ParseGraph |
| 区域推理 | [GeoShader，FLAIRS 2017](https://repository.lsu.edu/enviro_sciences_pubs/407/) | 在坐标图中分解 atomic regions，建立可饱和推导的分析超图 | 支持将 region、边界、分割和面积推导设为一等公民 |
| 定理形式化 | [FormalGeo，2023](https://arxiv.org/abs/2310.18021)、[AlphaGeometry，Nature 2024](https://www.nature.com/articles/s41586-023-06747-5) | 将题目变成 solver DSL，重点是表示和证明，而非从真实 raster 恢复证据 | 约束语言和 solver 可借鉴，但不得把 text-to-DSL 或人工形式题称为 image Parser |

公开实现还暴露了一个评测注意事项：PGDPNet 的官方 demo 没有实现文字识别，只能在 PGDP5K 上使用 GT text content。后续比较必须把 `primitive detection`、`OCR`、`grounding` 和 `full pipeline` 分开，不能把带 GT OCR 的结果写成端到端图片解析结果。

## 4. 最接近工作：Geoparsing / GDP-29K

### 4.1 已经覆盖的内容

Geoparsing 将 geometry diagram parsing 明确定义为“图片到符号表示”，并建立了统一 2D/3D 形式语言。公开数据字段包括：

```text
points
lines
circles
planes
structure
semantics
```

它还做了以下几件值得借鉴的工作：

- 线上点按顺序输出，避免只保留无序共线关系；
- 垂直关系显式带交点，例如 `AB \perp CD on X`；
- 3D 采用 point、line、plane、solid 的层次组合；
- 将 point/line、circle、plane、solid、semantic 分成层次化解析任务；
- 使用 SFT 学习语法，再用 RLVR 强化格式和类别级形式描述精度；
- 同时覆盖印刷图、手写图、平面图和立体图；
- 报告 primitive/semantic 的 precision、recall、F1，并验证形式描述对下游解题的增益。

官方已发布基于 Qwen3-VL-4B-Instruct 的 [GDP-4B 模型](https://huggingface.co/PeijieWang/GDP-4B) 和 [GDP-29K 数据](https://huggingface.co/datasets/PeijieWang/GDP29K)。因此第一轮不需要重训同类模型，可以先固定 revision 做离线预测导入和协议对比。

### 4.2 它没有覆盖的系统语义

根据论文、公开数据卡和仓库当前内容，可以确认或合理推断出以下边界：

- **没有 evidence grounding payload**：公开 schema 不含点坐标、文字框、笔画支撑、marker bbox 或证据引用；
- **没有 uncertainty contract**：输出没有 candidate confidence、score kind、冲突组、abstain 或 unsupported；
- **没有 provenance 与状态流转**：没有 observation -> hypothesis -> admitted fact -> derived fact 的运行时边界；
- **没有题干 target**：公开 GDP-29K 记录是图片和形式描述，不包含问题题干、求解目标或图文指代对齐；
- **没有 region/holes/shading**：公开字段和形式语言未描述区域集合、孔洞、阴影 mask 或边界表达式；
- **没有可执行 realization**：形式描述不携带精确坐标、自由度、分支、构造轨迹或重建 checksum；
- **没有无 GT admission**：论文所谓 geometric validity reward 实际按预测集合与训练 GT 集合的类别加权 precision 计算，不是部署时由几何内核独立证明图像语义；
- **主动过滤歧义样本**：数据构建会过滤语义歧义或文字不可识别的图片，而不是将歧义保存成多候选；
- **3D visibility 尚未显式建模**：论文限制部分明确指出目前没有区分可见与不可见虚线元素。

这意味着它与 Geosym-World 高度重叠于“确定性形式描述 baseline”，但没有覆盖可信 Parser 所需的审计与 admission 层。

另有一个需要复现实验时先核对的数据版本问题：论文正文写 28,977 个样本，而论文统计表和当前 Hugging Face 数据卡合计为 28,882。后续使用时必须固定数据 revision、逐条 hash 和 manifest，不能只记录名称 `GDP-29K`。

### 4.3 正确的竞争与复用关系

Geosym-World 不应重新训练一个没有差异的 image-to-string 模型来声称完成 Parser。更合理的是：

1. 为 GDP-29K / Geoparsing formal language 实现显式、可审计的 import adapter；
2. 将公开 Geoparsing 模型输出导入为 `PROPOSED` candidates，而不是直接写入 facts；
3. 补 evidence localization、冲突保留、题干 target、region、admission 和 reconstruction；
4. 同时报告原始 string/set 指标与 Geosym 分阶段指标；
5. 用失败样本验证 Geosym 层是否真正发现错点序、错绑定、漏交点和不一致条件。

### 4.4 已落地的第一步

Geosym-World 已新增严格的 `GeoparsingPrediction` 和 `GeoparsingAdapter`。适配器复用现有 `ExternalParseGraphPrediction`，支持公开语言中的点、顺序线、命名线、圆、平面、八类立体结构，以及垂直交点、平行链、线段等长/长度、角等量/角度和带数值弧度量。多字符点名采用声明点集上的唯一分词，不唯一时不猜。

接入边界保持保守：每条预测同时绑定公开 `ParserInput` checksum、图片 SHA-256、模型 revision 和 prompt version；没有模型置信度时明确记为未评分；由于公开格式不提供坐标或 bbox，所有候选只带 `IMAGE_ONLY` evidence，默认 admission 全部 abstain。无法表示的语法进入结构化 diagnostics，严格模式直接失败，partial 模式才保留可表示子集。`parse_reconstruct_v0` 已可通过 `--geoparsing-predictions` 重放这类结果，并在 manifest 中记录输入 hash、严格模式和 diagnostics 计数。

随后新增了保守的 `ParseGraphEvidenceFusion`。它只接受无冲突唯一点名以及唯一 endpoint/ordered-support/circle-center 映射，把 Geoparsing 对象引用重写到本地视觉对象；若本地已有完全相同的 typed relation/quantity/target，则复用本地候选而不重复创建。无法唯一映射的对象继续保留，外部候选的 `IMAGE_ONLY` evidence、confidence 和 admission 状态均不提升。`--fuse-geoparsing-visual` 可在同一 verified workflow 中组合 Geoparsing、OpenCV 和可选 OCR sidecar，并保存双图 checksum、逐候选 mapping 决策以及独立的 `compatibility_certificate`。证书现在还审计 marker relation 的 glyph 类型、marker 依赖完整性、support/marked-segment/ordered-angle 覆盖，以及已落地 quantity 的视觉文本 AST；但仍只提供兼容性审计，不改变 evidence precision 或 admission。

本步骤没有下载 GDP-29K、GDP-4B 或调用模型，也没有产生模型准确率。当前验证仅说明协议转换、引用融合与可信边界正确：Parser 重点回归集合 29 项通过，全仓 439 项通过。另已补充 hybrid batch 的公共输入投影、答案边界 fail-fast 和严格字段类型检查，并新增 line-name 的空间 binding。离线 grammar coverage audit 工具已经实现但尚未对固定 revision 的 GDP 全量数据运行；下一步应先执行该审计，再在经批准的小批真实预测上统计视觉 grounding、语法覆盖率和失败类型，最后决定扩展 grammar 还是训练本地组件。

## 5. 对“Parser 成功”的分级定义

建议不再只用一个 parsing accuracy，而是报告以下等级：

| 等级 | 成功条件 | 不能推出 |
| --- | --- | --- |
| P0 输入有效 | 图片、题干、版本和来源 hash 合法 | 看懂任何几何内容 |
| P1 Evidence | 图元、文本、符号、填充区域有局部证据 | 已正确绑定数学对象 |
| P2 Topology | 点、支撑线、圆弧、交点、点序和区域边界图成立 | 标注语义正确 |
| P3 Grounding | 名称、数值、符号、题干 span 与候选对象绑定 | 候选可被信任 |
| P4 Admission | schema、证据、冲突和几何检查允许接纳 source assertions | 已恢复唯一坐标或原始构造 |
| P5 Realization | 至少一个带分支与自由度说明的模型满足已接纳约束 | 该模型的偶然性质属于原题 |
| P6 Fidelity | 与可信 GT 或独立局部视觉证据一致，关键标注可回投 | 开放世界中的所有隐含语义均已恢复 |

每个样本可停在任一级并输出明确诊断。部分正确必须可保存；失败不能退化成空 JSON 或虚构完整 state。

## 6. 经过调研后的推荐架构

```text
Input Boundary
  -> Evidence Extractors
       raster primitives / OCR / math OCR / marker / fill
  -> Candidate Graph Builder
       objects / ordered incidence / topology / quantities / regions / target
  -> Model Proposers
       deterministic baseline / Geoparsing adapter / generic VLM
  -> Cross-modal Grounder
       image-image / text-image / marker-object / quantity-object
  -> Conflict Resolver
       retain alternatives / normalize aliases / no silent overwrite
  -> Admission Gate
       schema / policy / evidence / geometry / topology
  -> Reconstruction Planner
       exact trace / numeric witness / branch / underconstrained diagnosis
  -> Fidelity and Benchmark
       graph metrics / calibration / abstention / execution / local image alignment
```

模型实现可以是一体式 MLLM，但系统合同必须保持这些边界。这样才能替换模型而不改变 benchmark 真值和状态语义。

## 7. Benchmark 必须增加的指标

公开工作常用 primitive/relation F1、整题 exact match 和下游答题准确率。Geosym-World 应保留这些可比指标，并额外报告：

- evidence localization：point、stroke、text、marker、region 的定位与覆盖；
- binding：name-to-point、quantity-to-object、marker-to-support、target-to-object；
- topology：交点、线上点序、共享支撑、切触、区域边界和孔洞；
- graph exactness：忽略稳定 ID 表面差异后的 typed graph isomorphism；
- calibration：按 candidate type 的 confidence/reliability，而不是混合平均；
- selective parsing：coverage-risk、abstention precision 和 unsupported accuracy；
- admission：accepted/rejected/abstained 的正确性及拒绝原因；
- reconstruction：可执行率、退化率、自由度、分支覆盖、约束 residual；
- fidelity：关键局部回投、标注归属、可见性和 source redraw 差异；
- downstream utility：在固定 solver 下，Parser GT、预测 ParseGraph 和无图输入的差值；
- diagnosis：错误首先出现于 evidence、topology、grounding、admission、reconstruction 还是 solver。

## 8. 开发优先级调整

### 第一优先级：建立可比较 baseline

1. 冻结当前 ParseGraph evaluator 和阶段指标；
2. 实现 Inter-GPS/PGDP/GDP-29K 至少一种公开格式 adapter；
3. 定义 provider-neutral 的整图 VLM prediction contract，继续使用 checksum-bound replay；
4. 同一输入同时跑确定性 v0、直接 VLM、公开专用 Parser；
5. 不先训练模型，先测清三类 baseline 的错误矩阵。

### 第二优先级：完成可信解析闭环

1. 补通用 OCR 和数学 OCR，但始终保留区域级证据；
2. 完成点序、匿名交点、圆弧、marker 和 quantity 的多候选 grounding；
3. 将 region、hole、component、difference 和 shaded target 纳入正式评测；
4. 增加 conflict-group admission、撤销和依赖失效；
5. 将 admitted constraints 编译为 exact trace 或显式 numeric witness。

### 第三优先级：再决定是否训练专用模型

只有在错误矩阵表明高频错误不能由 adapter、候选器或 grounding 修复时，才训练专用模型。可选方向依次是：

1. OCR/marker/primitive 的局部专用模型；
2. candidate graph relation scorer；
3. constrained ParseGraph decoder；
4. 以 admission、拓扑和局部 evidence 为奖励的训练；
5. 2D 稳定后再扩展 3D visibility、plane/solid 和投影歧义。

## 9. 最终判断

别人对 Parser 的主流理解已经从“检测线和文字”发展到“图片直接生成形式描述”。因此，**image-to-formal-language 本身已经是明确且拥挤的路线**，特别是 Geoparsing 已覆盖统一 2D/3D。

Geosym-World 仍有清晰的工程与研究空间，但应放在以下组合上：

- evidence-bearing，而不是只有最终字符串；
- ambiguity-preserving，而不是只接受干净无歧义图；
- verifier-gated，而不是模型输出即事实；
- region-aware，而不是只支持 points/lines/circles；
- reconstructable，而不是只供语言模型阅读；
- diagnostically benchmarked，而不是只报告最终 F1 或答题率。

本轮检索中没有发现一项公开工作同时完整实现上述六点。这只是当前检索范围内的结论，不能直接写成未经更系统 novelty review 的论文新颖性声明。
