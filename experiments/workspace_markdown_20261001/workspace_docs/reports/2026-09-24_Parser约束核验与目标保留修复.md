# Parser 约束核验与目标保留修复

## 本轮范围与结论

本轮优先落实 2026-09-23 审计中的 P0：约束假通过、target 丢失，以及对象物化覆盖不透明。未修改模型输出中的错误几何条件，未针对某个数据集改写点名或数值，也未调用 VLM。没有创建 commit；保留仓库原有重构改动。

这次主要改善状态模型和结果可信度，八张图的视觉质量没有明显改善。圆半径量纲、圆弧物化、PGDP 错误条件和标记显示仍未解决，不能把本轮称为完整重建修复。

## 已完成

1. 中点关系统一支持“点 + 支撑线段”和“点 + 两端点”。参数角色乱序不改变意义；参数数量、角色和重复引用有明确校验。优化、核验、State 关系使用一致的端点。
2. 未处理的关系检查不再默认返回 true。零长度方向不再误判平行或垂直；关系必须实际进入 State 的独立验证路径，才能报告 satisfied。精确构造分支也补入已核验的关系。
3. 数值中点使用显式 numeric_witness 容差核验；精确状态继续使用符号等式，不统一放宽验证。
4. target 的 query 归为 value；缺省模式按测量/命题类型确定；未知模式明确报错。已声明 region 不再仅因不是 object 而被误报为缺失。
5. 可绑定的单一求值 target 通过 set_target 写入 Geometry State 和可重放 trace，保留原始 target、confidence、evidence、来源图 checksum 和候选实例作用域。不会把目标加入优化器前提。
6. 全部 target 保存在 realization.metadata.task_targets；target_outcomes 区分 bound 与 unsupported。多目标、未绑定目标以及当前实现不支持的目标契约不会静默覆盖或改义。
7. materialization 单独记录缺失 object、region、target ID。存在 State 但覆盖不完整时报告 partial；constraint_satisfied 仍单独回答输入条件是否满足，不将目标当作已知条件。

实现复用现有 schema、SeedRealizer、ConstructionBuilder、TraceVerifier 和 pipeline，没有增加平行 Parser。

输入来自 multisource_pipeline_v13_20260923 的八份冻结原始 VLM JSON，重新经过当前适配器编译和完整 Parser 管线。使用原图和原有可选题目文本；不读取答案或 formal state 作为输入。请求函数被离线响应替代，网络调用为 0。

最终目录：`/data/Geosym127K/Geosym-World/artifacts/parser/evaluations/seed_repair_20260924/final/`。

- `contact.png`：八图原图/候选重绘总览。
