# Agent 人工重建多源几何图实验

## 目的

本实验暂时忽略现有 Parser，实现一次独立的人工基线：Agent 直接观察原图和题目文本，判断几何对象、拓扑、关系与可见标注，再使用 Geosym-World 的正式 `ConstructionBuilder`、Geometry State、`TraceVerifier` 和 renderer 完成重建。

实验不调用 VLM、OCR、OpenCV、Parser 模块，不读取 Parser JSON、scene metadata 或数据集 formal state。人工确定的是数学结构；坐标是一组满足结构约束的合法实现，不追求恢复原图像素坐标。

## 实现流程

```text
原图 + 题目文本
    -> Agent 人工识别对象与关系
    -> 显式 construction trace
    -> ConstructionBuilder
    -> canonical Geometry State
    -> TraceVerifier
    -> renderer-neutral scene
    -> SVG / PNG / 原图对照图
```

每个样本单独保存：

- `trace.json`：可重放构造轨迹；
- `state.json`：含精确坐标、对象、关系和 target 的 Geometry State；
- `verification.json`：严格 trace/state 验证结果；
- `scene.json`：renderer-neutral scene；
- `reconstruction.svg` 与 `reconstruction.png`；
- `review.png`：原图与重建图并排对照；
- `notes.md`：该图的人工判断、建模选择与不确定项。

## 样本覆盖

本轮共 8 张，来自 Geometry3K、MATH-Vision、PGDP 和 GeoQA，覆盖：

- 三角形中线、三组中点和重心；
- 圆、弦、半径和垂直关系；
- 长方形、延长构造、交点和面积 target；
- 四分之一圆、内切圆和根式半径；
- 多边形面积图、对角线、两条高；
- 菱形、四边等长和高；
- 三角形面积分割、垂足和可见辅助线。

## 关键实现原则

1. 所有数学对象先进入 Geometry State，颜色、虚线和填充只在 scene 层调整。
2. 严格关系使用精确有理数或根式坐标，不用近似浮点冒充垂直、等长或共线。
3. 原图未给出名称的支撑点保留稳定内部 ID，但不显示点名和点标记。
4. 原图可见但数学角色不确定的虚线保留为辅助对象，不擅自提升为 theorem fact。
5. 自动发现但原图未标注的隐式交点不显示，也不自动分配点名。
6. 相同刻线表示同一等长组；不同等长组使用不同刻线数量，避免语义混淆。
7. 题目给出的数值进入对象 metadata；只有原图本身显示数值时才在重绘图中显示。

## 结果

- 8/8 construction trace 可执行；
- 8/8 通过 `TraceVerifier`；
- 8/8 verification error 为 0；
- 8/8 生成 canonical state、SVG、PNG 和 review 图。

本结果说明：只要对象、拓扑与关系判断正确，Geosym-World 现有内核足以把这组 2D 题图实现为合法 Geometry State 并稳定重画。当前自动 Parser 的主要缺口不是 renderer，而是如何可靠地产生与本人工基线等价的对象绑定、关系约束和“应显示/不应显示”的证据决策。
